# Editor UI kit

Three screens composed from `components/core`: **Entry** (`/`), **Editor** (`/p/{id}`, tuning state — sliders, tabs, unsaved guard and Save toast are live), **Help** (`/help`). `ClonedPage.jsx` is the generic pricing-page stand-in for a cloned client page; `TopBar.jsx` is the 44px violet bar.

Open `index.html`; the strip at the top switches screens and is not part of the product.
