Button for every action: primary violet, secondary outlined, bar variants for the top bar, danger as a red text link.

```jsx
<Button variant="primary" glow>Save</Button>
<Button variant="secondary" icon="✦">Auto-generate for this page</Button>
<Button variant="danger">Remove animation</Button>
```

Primary is the only filled violet control on screen. `bar`/`barPrimary` are 28px and live only in the top bar. `danger` is a text link, never filled.
