Text field; size xl with prefix "https://" is the entry URL field, sm with a ⌕ prefix is search.

```jsx
<Input size="xl" prefix="https://" value="nimbus.app/pricing" />
<Input size="sm" prefix="⌕" placeholder="Search animations" />
```

error state = 1.5px red border + red glow; the message goes under the field, not inside.
